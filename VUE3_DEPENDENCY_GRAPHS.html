The 101-File Core Cycle critical risk

Tarjan's SCC analysis reveals one massive strongly-connected component of 101 files. This simplified view shows the hub nodes — in reality, every file in the cluster transitively depends on every other. This cycle must be broken (Phase 0) before any meaningful extraction is possible.

Why this matters: You cannot safely extract any of these files in isolation. Splitting script.js into chat-engine.js + character-manager.js would still pull the entire cluster because of bidirectional imports. Phase 0 introduces a central core/state.js that owns all mutable bindings, breaking the cycle by indirection.
